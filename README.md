## 🚀 Deployment to Vercel

The project is pre-configured with `vercel.json` and synchronized with the GitHub repository:
`https://github.com/pratyushrajskpr-wq/PR-Prime-Projects.git`

### To Push to GitHub from Git Bash:
```bash
git add .
git commit -m "Refine PR Prime Projects: fix header cut bug, add Hero search, Pan-India & Delhi NCR hubs, social links, and floating action dock"
git push -u origin main
```

When connected to Vercel, any push to `main` deploys automatically within seconds.
